Neuromorphic acoustic detection — field report

Eco⁠-⁠Sentry

Anti‑poaching acoustic detection for Indian forest reserves. Listens for gunshots, chainsaws and vehicles, classifies them on a spiking neural network, encrypts the detection into a sub‑1 KB alert, and delivers it to a command centre over a simulated LoRa mesh — while a power model tracks whether the solar‑charged edge node survives a 30‑day deployment.

Quick start

Install dependencies and run the full pipeline end to end.

Installation

pip install -r requirements.txt

Run the full pipeline (quick preset, ~16 seconds)

python -m ecosentry run --preset quick

Run full fidelity (~7 minutes, 600 clips, 120 epochs)

python -m ecosentry run --preset full

Classify a single audio file

python -m ecosentry infer --audio clip.wav --payload

Run tests

python -m pytest tests/ -q
